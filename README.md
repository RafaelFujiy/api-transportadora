API de Transportadoras

API simples com CRUD de transportadoras, feita como treino de backend.

Como rodar
1. npm install
2. node server.js
3. Acesse http://localhost:3000/transportadoras

Endpoints
- GET /transportadoras — lista todas
- GET /transportadoras/:id — busca uma pelo id
- POST /transportadoras — cria uma nova
- PUT /transportadoras/:id — atualiza
- DELETE /transportadoras/:id — remove
